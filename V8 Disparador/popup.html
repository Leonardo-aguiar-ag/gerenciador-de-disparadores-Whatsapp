Início:

🚀 Começar em 3 passos

  1. Abra o WhatsApp Web e faça login
  2. Escreva os scripts na aba SCRIPTS (deixe os que quer usar marcados)
  3. Cole a lista em DISPARO ou várias listas em LOTE e clique em ▶ INICIAR

📚 LOTE (envio sequencial)

Envia várias listas em sequência usando os scripts ativos da aba SCRIPTS.

  1. Na aba SCRIPTS, marque as caixas dos scripts que deseja usar
  2. Vá em LOTE e clique em ➕ ADICIONAR LISTA
  3. Em cada card, preencha apenas nome e números
  4. Clique em ▶ INICIAR LOTE

▶ DISPARO

Cole a lista de contatos, um por linha:

85999999999;João Silva
85888888888;Maria
85977777777

📁 IMPORTAR EXCEL/CSV — carrega lista de arquivo (.xlsx, .xls, .csv, .txt). Aceita 2 colunas: número e nome.

✍️ SCRIPTS

Cada caixa marcada é uma variação. Use:

  • [NOME] → nome do contato
  • {Oi|Olá|Ei} → sorteia uma das opções

🎯 CAMPANHAS

  • Normal — 1 mensagem por contato
  • A/B — testa variantes alternadas (cada variante pode ter vários scripts)
  • Drip — sequência em vários dias (use o botão próprio)

📊 CRM

Dashboard do topo: Total, OK, Erros, Respond., Digitando.

Taxa de conversão: barra colorida com % OK / Erro / Duplicado.

Envios nos últimos 7 dias: gráfico de barras com volume diário.

Filtros de data: Hoje · Ontem · 7 dias · 30 dias · Tudo (combinam com a busca).

Botões: 📥 Exportar tudo · ✅ Só respondidos · 💾 Backup · 📂 Restaurar · 🗑 Limpar

Clique no 📝 de qualquer linha para adicionar uma nota pessoal.

⚙️ CONFIG

👥 Perfis: salva config + scripts + campanhas + lista num perfil. Use o dropdown para trocar.

Delay: tempo aleatório entre mensagens (recomendado 15–30s).

Pausa por lote: descansa após X envios por Y minutos.

Horário comercial: só dispara dentro da janela.

Duplicatas: pula números já enviados recentemente.

Warm-up: limite diário crescente (número novo).

💡 Dicas rápidas

  • Mantenha o WhatsApp Web aberto durante o disparo
  • Comece com poucos contatos para testar
  • Números novos: ative o Warm-up
  • Use 🔄 RETOMAR se algo travar
  • Faça backup manual antes de disparos grandes
