Guia do Gerenciador

Use esta tela como roteiro. Para enviar pelo WhatsApp Web, mantenha o WhatsApp aberto, conectado e com a extensão recarregada.

Dashboard / CRM

Métricas: mostra total de resultados, envios OK e erros. Taxa de conversão: calcula o percentual de resultados OK. Gráfico: resume os envios dos últimos 7 dias. Filtros: mostram hoje, ontem, 7 dias, 30 dias ou todo o histórico. Buscar: localiza nome, telefone ou status. Exportar: baixa os registros em JSON. Limpar visualização: limpa somente a lista exibida, sem apagar o histórico salvo.

Quando o backend não estiver ativo, os disparos pelo WhatsApp Web aparecem no histórico local desta extensão. Contatos, listas de lote, rascunhos de scripts, nome da campanha, configurações e progresso da fila são preservados automaticamente.

Disparos

Arquivo de contatos: importe CSV/TXT. Lista: cole uma linha por contato no formato telefone;nome;campo1;campo2. Pré-visualizar: valida telefones e mostra exemplos com o primeiro script. Iniciar Disparo: envia diretamente pelo WhatsApp Web no modo Web; em Simulação ou Cloud API usa o backend. Pausar: pausa entre contatos. Parar: encerra a fila atual. O andamento aparece em total, sucesso, contato atual, tempo e estimativa.

Atenção: use apenas contatos com autorização e respeite as regras do WhatsApp. O modo WhatsApp Web precisa de uma aba aberta e conectada; o modo Simulação não envia mensagens.

Scripts

Variações: cadastre até 20 mensagens. Salvar: guarda a versão no backend ou localmente se ele estiver desligado. Importar: aceita JSON ou TXT; no TXT, separe cada mensagem com uma linha contendo apenas ---. Exportar: baixa as mensagens em JSON. Histórico: selecione uma versão para editar ou excluir. Use [NOME] e spintax como {Oi|Olá}.

Lote

Nome do lote: identifica o conjunto de listas. Listas: informe uma lista por bloco, separando blocos por uma linha vazia. Iniciar Lote: processa a primeira lista e informa quantas ficaram aguardando revisão. Parar Lote: cancela a fila do lote atual.

Configurações

Perfis: salvam listas, scripts e preferências para reutilização. Modo: escolha WhatsApp Web, Simulação ou Cloud API. Delays: definem o intervalo entre envios. Pausa por lote: cria pausas após uma quantidade de contatos. Horário comercial: restringe dias e horários. Duplicatas: evita números repetidos. Warm-up: controla um limite diário crescente. Salvar configurações: aplica as escolhas. Verificar conexão: testa WhatsApp Web ou backend. Backup: cria ou restaura dados do backend.

Estados e soluções rápidas

Backend indisponível: o Dashboard usa os registros locais e o modo WhatsApp Web continua disponível; Simulação e Cloud API precisam do backend. WhatsApp não conectado: abra web.whatsapp.com, leia o QR Code e recarregue a extensão. Nenhum envio: faça a prévia, confirme telefones com DDI/DDD e verifique se existe pelo menos um script.
